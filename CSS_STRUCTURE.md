# CSS Структура проекта BitForce

## Обзор
Проект использует модульную структуру CSS для лучшей организации и поддержки кода. Каждая страница имеет свой CSS файл, а общие стили вынесены в отдельные модули.

## Структура файлов

### 1. `src/index.css` - Глобальные стили
- Сброс стилей браузера
- Основные стили для body, ссылок, кнопок, input
- Стили для Material Icons
- Утилиты (скрытие, фокус, анимации)

### 2. `src/layout.css` - Общие стили макета
- Плавная прокрутка
- Основной контейнер приложения
- Header и навигация
- Hero секция
- Основной контент
- Footer
- Общие стили для страниц (page-container, page-header, page-title, etc.)
- Общие стили для карточек и кнопок
- Общие стили для статусов
- Адаптивность

### 3. `src/App.css` - Стили для App компонента
- Основной контейнер приложения
- Info Banner стили
- Стили для LoadingScreen
- Блокировка скролла при открытом меню
- Анимации

### 4. `src/components/components.css` - Стили для общих компонентов
- EditProfilePanel

- Статусы, бейджи, разделители
- Утилиты (grid, flex, иконки, ссылки, tooltip)
- Сообщения (ошибки, успех, предупреждения, информация)
- Адаптивность

### 5. `src/shared/utils.css` - Утилитарные классы (НОВЫЙ)
- Общие контейнеры (page-container, page-wrapper)
- Общие заголовки страниц (page-header, page-title, page-subtitle)
- Общие секции пулов (pools-section, pools-header, pools-title)
- Общие карточки пулов (pool-card, pool-header, pool-title)
- Общие кнопки и действия (pool-btn, pool-refresh, refresh-all-btn)
- Общие информационные карточки (info-cards, info-card)
- Общие статусы пулов (pool-status)
- Адаптивность

### 6. `src/shared/pools.css` - Специализированные стили пулов (НОВЫЙ)
- Комплексные layouts пулов (pools-content, pools-grid)
- Продвинутые компоненты пулов (pool-progress, pool-actions)
- Специальные стили для сложных pool-section layouts
- Адаптивность для комплексных пул-секций

### 7. `src/pages/Home.css` - Стили для главной страницы (ОЧИЩЕН)

### 8. `src/pages/Buy.css` - Стили для страницы покупки (ОЧИЩЕН)

### 9. `src/pages/Sell.css` - Стили для страницы продажи (ОЧИЩЕН)
- Sell-специфичные стили с префиксом sell-

### 10. `src/pages/Profile.css` - Стили для личного кабинета

## Принципы организации

### 1. Модульность
- Каждая страница имеет свой CSS файл
- Общие компоненты вынесены в `components.css`
- Общие стили макета в `layout.css`

### 2. Префиксы классов
- `home-*` - для стилей главной страницы
- `buy-*` - для стилей страницы покупки
- `sell-*` - для стилей страницы продажи
- `profile-*` - для стилей личного кабинета
- `component-*` - для общих компонентов

### 3. Адаптивность
- Медиа-запросы для планшетов (max-width: 1024px)
- Медиа-запросы для мобильных (max-width: 768px)
- Медиа-запросы для маленьких экранов (max-width: 480px)

### 4. Переиспользование
- Общие стили для кнопок, карточек, статусов
- Единая система цветов и типографики
- Консистентные отступы и размеры

## Преимущества оптимизированной структуры

### ✅ Исправлено в этой версии:
1. **Устранены дублирования**: Удалены повторяющиеся стили (.info-banner, .pools-section)
2. **Предотвращены конфликты**: Использование префиксов классов для страниц
3. **Создана общая библиотека**: Shared-стили для переиспользования
4. **Уменьшен размер бандла**: Отсутствие дублирующегося CSS кода
5. **Улучшена консистентность**: Единые стили для схожих компонентов

### 🎯 Общие преимущества:
1. **Лучшая организация**: Каждая страница имеет свой CSS файл
2. **Изоляция стилей**: Стили не конфликтуют между страницами  
3. **Легкость поддержки**: Легко найти и изменить стили для конкретной страницы
4. **Переиспользование**: Общие стили вынесены в shared/ модули
5. **Масштабируемость**: Легко добавлять новые страницы и компоненты
6. **Производительность**: Загружаются только необходимые стили

## Рекомендации по разработке

1. **Новые стили**: Добавляйте в соответствующий файл страницы
2. **Общие стили**: Используйте существующие классы из `layout.css` и `components.css`
3. **Префиксы**: Всегда используйте префиксы для новых классов
4. **Адаптивность**: Добавляйте медиа-запросы для всех новых стилей
5. **Документация**: Обновляйте этот файл при изменении структуры
